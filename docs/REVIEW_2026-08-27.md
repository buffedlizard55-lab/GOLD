## 2. Threshold arithmetic (recomputed, not copied)

```
price_per_gold_oz = price_usd ÷ (weight_g × karat_purity) × 31.1034768
```

### 6.3 P1 — Costco price drift is real and only partly detectable
One of six Costco gold-band rows repriced +36% in eight days (§4.1) while another renders its price only as "Loading" (§4.3). ### 6.4 P1 — "one row per URL" suppresses legitimately distinct products
Costco sells 13 sizes × 2–3 metals per product page at one URL, each with its own published gram weight; Menē sells ~20 sizes per URL; Chow Sang Sang exposes per-weight variants as distinct URLs (`…-WT-0.1820`) while Chow Tai Fook does not. ### 6.5 P2 — weight opacity remains the binding constraint
Sellers checked this session that publish price but **no** gram weight: Menē (all bands), Sam's Club, GoldenMine, Midwest signets. Sellers that publish weight but **no** price: Hua Seng Heng (all 23 rings). Sellers that publish both but price far above melt: Costco, Ross-Simons, Chow Tai Fook, Midwest's diamond rings, JTV, Shop LC, TraxNYC, Pompeii3. **There is no large seller that publishes both weight and a near-melt price** — which is precisely why the threshold yields so few rows.

### 8.4 The finding that bounds the problem

Computed directly from `data/rings.json` (473 rows):

```
rows with a computable price_per_gold_oz : 222
of those, men's / unisex                 :  13
of those, below $4,861 / pure gold oz    :   3
```

**Only 13 men's or unisex rings in the entire verified directory publish both a price and a gram weight.** Of those, 3 clear the threshold. A 50-row men's list therefore cannot be assembled from verified data — **even if the $4,861 threshold were removed entirely**, the ceiling on that list is 13 rows.
