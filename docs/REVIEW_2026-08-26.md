- Pages API: `https://api.github.com/repos/buffedlizard55-lab/GOLD/pages`
  - `"build_type": "legacy"`, `"source": {"branch": "main", "path": "/"}` — i.e. **root**, not `/docs`.
  - Latest build: `9dcc757...`, status `built`, pushed by `arena-ai-coding-agent[bot]`, 2026-08-25T18:23:42Z.
- Because the root has no `index.html`, GitHub Pages renders **README.md as the homepage**. I fetched `https://buffedlizard55-lab.github.io/GOLD/` and it returns the README as rendered HTML — **no table, no source links, no karat/price columns, no data**.
- The actual app (table + filters + source links) exists at `docs/index.html` with `docs/data/rings.json` (487 rows), but it is **never deployed** because Pages reads the root.

## 4. Irregularities flagged for review (highest severity first)

1. **P0 – Site not deployed:** Pages publishes root instead of `docs/` → live URL shows the README, no table/links/prices. See §1.
2. **P0 – "Verified" is a claim, not a reality:** 290/487 rows have no weight, and 262 have no weight at all — the README's "every row provides…" statements are false. ~41 % of my 27-row sample was wrong.
3. **P0 – Data errors already proven** (live-verified): Baby Gold $450→$720; Costco $599.99/size 4.5→$829.99/size 7; Automic Alexandrite $325/0.49 g→$526–625/no weight; Quince Circle Eternity $148/1.0 mm→$228/2.5 mm; Quince Pave Gemstone $299.90→$398; Quince 3-Stone Inlay $428→$468; Quince Ridge $248→$278; 7879 Signet $4,617 USD→£3,485.99 GBP (sold out, no weight/no USD breakdown on page); Menē band rows internally inconsistent (3 rows/one URL; engraved cheaper than plain).
4. **P0 – Same official URL used by multiple rows with different data (33 duplicate URLs, 100+ rows involved):** e.g. Ritani `cordelia_round_18k_wg` **$900** vs `cordelia_round_18k_wg_2` **$2,970 / 4.9 g** — same product page, two prices; `amata` pair identical; `rainbow_band` pair identical; Menē narrow = 3 rows. This inflates the "487" count and makes conflicting claims unverifiable. (Not auto-fixed in this pass — needs a dedupe decision.)
5. **P0 – Audiovisual physics:** weights 0.1–0.7 g for "solid gold rings" (Automic Cable 0.1 g, Bead 0.3 g, Mini Miami 0.3 g, Alexandrite 0.49 g…) are physically implausible for solid gold jewelry (solid metal rings are ≥1 g even at 0.85 mm); likely unit/estimation errors — re-verify each against the seller page.
6. **P1 – Collection/list pages used as per-product "official source"** with per-product prices: 7 Quince rows cite one Stackable collection URL; 3 Ferko's rows cite `/collections/…`; 18 Ritani rows cite `/collections/…`; several Automic/Baby Gold rows cite `/collections/…`. A listing page can confirm existence, **not** a specific product's price/weight.
7. **P1 – Blue Nile row cites the exact URL `_rejected.md` says was rejected** — internal contradiction (rejected list vs compiled dataset).
8. **P1 – Missing advertised features:** no calculator, no size-4.5 investigation, no anti-fraud checklist, no CI workflows — README lists all of them as existing.
9. **P1 – Audit is inert:** `bash scripts/audit.sh` exits 0 while the above errors are present. Check 1 greps for the *string* `"source_url"`; Check 2 scans `index.html` (which has zero row prices, so it always passes); Check 3 only scans lines containing `"./…"`/`'./…'` for literal `https://` (current `scripts.js` loads `data/rings.json` via `DATA_URL`, bypassing the check); Check 4 checks only that a date string exists, not that it is valid/2026. It cannot detect any of the failures above. The scripts/README.md honestly says so ("intentionally dumb… A human still needs to read the source links"), which contradicts the project's "automated audit verifies" claim.
10. **P1 – Currency/dates:** all prices assumed USD with no currency field (7879 shows GBP; Menē prices update daily — rows aged 7–9 days are already stale). `verified_on` is a string, no source snapshot/citation, so nothing proves the value was read on that date.
11. **P2 – Hallmark fields are assertions, not quotes:** e.g. "24K (99.9% pure solid gold)", "London Assay Office hallmark", "18K (per Ritani spec)" — none of these are hallmark quotes from the pages (Ritani page says "18kt Yellow Gold"; 7879 page says "Hallmarked in the UK" generically). Should be reworded to what the page actually states.
12. **P2 – Non-ring rows + non-user content in a "ring directory"** (§3 rows 26–27) and seller labels that inflate "35 retailers".
13. **P2 – Repo hygiene:** `add_rings.py` is dead code referencing a UI structure that no longer exists; `_rejected.md` instructs editing `EVIDENCE_FILES` in `scripts.js` which no longer exists; README's layout section shows files that aren't there.
